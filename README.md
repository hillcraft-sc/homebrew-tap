# Homebrew tap for OneRoot

[OneRoot](https://oneroot.hillcraft-sc.com) is a fast, native file manager for macOS.

```
brew install --cask hillcraft-sc/tap/oneroot
```

If Homebrew asks you to trust the tap first, run `brew trust hillcraft-sc/tap` and try again.

Update with `brew upgrade --cask oneroot`. Requires macOS 14 Sonoma or later.

Issues with OneRoot itself: https://github.com/hillcraft-sc/OneRoot/issues
